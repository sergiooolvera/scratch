📄 Formato de Examen PDF — Guía para Profesores

Utiliza este documento como referencia para crear tu archivo PDF de evaluación

📋 Instrucciones de Formato

  • Cada pregunta debe iniciar con "Pregunta N" o con un número seguido de punto (ej. 1.). Obligatorio
  • Las preguntas de opción múltiple deben tener exactamente 4 opciones, cada una en su propia línea. A, B, C, D
  • La respuesta correcta se indica entre paréntesis al final del bloque: (A), (B), (C) o (D). Obligatorio para opción múltiple
  • Todos los exámenes deben contener únicamente preguntas de opción múltiple. No se permiten preguntas abiertas.
  • El sistema acepta 2 formatos. Elige el que te sea más cómodo. Ambos se detectan automáticamente.
⚠️ Importante • No uses tablas, imágenes ni columnas. El texto debe fluir línea por línea.
• Cada opción (A, B, C, D) debe estar en su propia línea separada.
• Asegúrate de que el PDF sea de texto (no imagen escaneada).
• Puedes crear el PDF desde Word, Google Docs o cualquier editor de texto.
• Para descargar este ejemplo como PDF, haz clic en el botón de abajo o usa Ctrl+P → "Guardar como PDF".
